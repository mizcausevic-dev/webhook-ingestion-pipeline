# Security Policy

## Supported Versions

This repository is a portfolio project and is maintained on a best-effort basis. The `main` branch is the supported version.

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities. Instead, contact Mirza Causevic through LinkedIn or the contact form on `mizcausevic.com` with:

- affected file or endpoint
- reproduction details
- potential impact
- suggested remediation if known

The project intentionally uses sample secrets, demo payloads, and mock provider workflows only. No production credentials should ever be committed to this repository.
